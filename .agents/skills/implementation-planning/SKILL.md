# Implementation Planning

## Overview

Use this skill to turn requirements into a concrete execution plan without starting implementation yet.

## Workflow

- Break the work into phases or tasks.
- Identify the files, modules, or systems likely to change.
- Note the validation steps for each phase.
- Provide sequencing guidance so the work can be completed incrementally.

## Gates

- Ask the user to review the plan before implementation begins.
- If the plan depends on a major design decision, pause and surface the decision point.

## Response Shape

- Implementation plan
- Phases or tasks
- Affected files or systems
- Validation strategy
- Open questions for review
