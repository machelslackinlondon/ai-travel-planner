# Architecture Comparison

## Overview

Use this skill when multiple implementation strategies are plausible and the best option depends on maintainability, complexity, performance, or repository conventions.

## Workflow

- Identify the key architecture options.
- Compare each option for correctness, complexity, maintainability, performance, and risk.
- Highlight the trade-offs and recommend a preferred path.
- Summarise what would change if the alternate option were chosen.

## Gates

- Ask the user to choose the preferred design if the recommendation is not decisive.
- If the decision would materially affect cost, risk, or scope, pause for explicit approval.

## Response Shape

- Candidate options
- Trade-off analysis
- Recommended option
- Decision points for the user
