# Plan Review and Refinement

## Overview

Use this skill to make the implementation plan explicit, collaborative, and ready for execution.

## Workflow

- Present the plan clearly and highlight the major decisions.
- Invite the user to correct priorities, scope, or sequencing.
- Incorporate feedback and revise the plan.
- Confirm that the plan is acceptable before proceeding.

## Gates

- If the user objects to scope, order, or constraints, stop and revise the plan.
- If the plan lacks critical detail, ask for additional input rather than guessing.

## Response Shape

- Reviewed plan
- User feedback incorporated
- Revised priorities or scope
- Approval to proceed
