# Solution Explanation

## Overview

Use this skill when the implementation is complete and a concise explanation is needed for the user or a review audience.

## Workflow

- Summarise what changed and why.
- Highlight the key design and implementation decisions.
- Cover the constraints, assumptions, and notable trade-offs.
- Tailor the explanation for the audience, such as a teammate, reviewer, or interviewer.

## Gates

- If the user wants a different level of detail, ask for the intended audience before preparing the explanation.

## Response Shape

- Solution summary
- Key decisions
- Trade-offs and assumptions
- Optional follow-up notes
