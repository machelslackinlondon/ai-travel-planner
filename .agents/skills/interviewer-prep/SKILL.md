# Interviewer Preparation

## Overview

Use this skill after the solution is explained to prepare for technical discussion, design review, or interview-style questioning.

## Workflow

- Identify the most likely questions about the implementation.
- Draft concise answers that explain the approach, trade-offs, and reasoning.
- Include follow-up points that show awareness of limitations or alternatives.

## Gates

- If the user wants a specific audience or role, ask for that context before drafting the responses.

## Response Shape

- Likely questions
- Sample answers
- Key talking points
- Optional follow-up discussion
